# 豆瓣Top250电影爬虫与数据清洗项目
> 技术栈：Python3 | requests | lxml | XPath | openpyxl

## 项目介绍
本项目实现豆瓣Top250榜单数据采集、本地持久化、数据清洗、结构化导出全流程。
采用**采集与解析分离**的设计思路：先一次性拉取网页源码保存本地，后续调试解析规则不再重复请求网站，降低反爬风险。
清洗后的数据导出为带筛选、冻结表头的Excel文件，可直接用于数据分析。
> ⚠️ 本项目仅用于Python爬虫学习练习，禁止高频抓取、商用。

## 功能特性
- 模拟浏览器UA请求，循环翻页采集豆瓣Top250共10页页面
- 原始网页本地持久化保存，方便迭代调试、新增字段
- 使用XPath解析网页，提取排名、片名、外文名、导演主演、上映信息、评分、评价人数
- 数据清洗：清除\xa0不间断空格、换行空白；封装安全取值函数，兼容缺失字段，避免IndexError
- 结构化输出Excel，支持表头冻结、自动筛选

## 项目结构
```
├── 豆瓣top250.py            # 爬虫采集脚本，下载html源码
├── 清洗数据.py               # 控制台打印清洗后数据，用于调试查看
├── 豆瓣Top250导出Excel.py    # 数据清洗 + 导出Excel
├── 1.html~10.html            # 存放原始网页文件
├── 豆瓣Top250.xlsx           # 导出的结果表格
└── README.md                 # 项目说明文档
```

## 运行方式
1. 安装依赖
```bash
pip install requests lxml openpyxl
```
2. 第一步：执行爬虫，下载网页
```bash
python 豆瓣top250.py
```
3. 第二步：清洗并导出Excel
```bash
python 豆瓣Top250导出Excel.py
```

## 遇到的问题与解决方案
1. 反爬风险：采集、解析解耦，仅采集阶段访问网站，调试阶段读取本地HTML，减少请求次数
2. IndexError索引越界：部分电影没有外文名，XPath返回列表长度不足。封装取值函数，读取下标前判断列表长度，缺失字段填充空字符串
3. 脏数据：网页存在\xa0特殊空白字符，统一清洗替换
